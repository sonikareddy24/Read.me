## About Me

<details open>
<summary><b>System Architecture & Engineering Background (Click to Collapse/Expand)</b></summary>
<br/>

I am a **Computer Science Engineer** and **AI/ML Researcher** focused on architecting resilient intelligent systems and exploring the synergy between neural cost modeling, compiler optimizations, and computer vision.

- **Current Initiatives:** Developing **VeriDocs AI** (deterministic document fraud-consistency engine) and **NS-IR** (neural-symbolic compiler optimization pipeline).
- **Core Specialization:** Deep Learning Architectures, Neural-Symbolic AI, Medical Image Segmentation, and Cryptographic Security Benchmarks.
- **Current Trajectory:** Large Language Model reasoning loops, Graph Neural Networks for intermediate representations, and high-concurrency event-driven backends.
- **Engineering Principle:** *"Extraction proposes; deterministic code decides."*
- **Operating Philosophy:** *"Learn. Build. Research. Repeat."*
